**我可以在 Michaels 门店使用优惠券吗？** 门店不发放纸质优惠券。你可以在手机上使用移动应用中的代码和优惠，而门店的 25% 单品优惠需要从 Savings 页面扫描条形码。

**我可以在一张订单中叠加使用两张优惠券吗？** 每件商品限一张，每种类型每天限一张。你可以将一张优惠券与促销定价、Rewards 优惠和现金返现结合使用，但不能叠加使用两张代码。

**为什么 GETMY20 没有折扣我的购物车？** 通常是因为购物车里的商品属于排除清单 —— 通常是促销/清仓价格、Cricut 或 Lego 品牌、定制画框，或者来自第三方卖家的商品。
